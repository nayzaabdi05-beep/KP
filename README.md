#  Dashboard Analisis Waktu Pemenuhan Material Request (MR)
**PT Epsindo Jaya Pratama Workshop Duri**

Dashboard interaktif berbasis web ini dikembangkan menggunakan **Streamlit** untuk menganalisis waktu pemenuhan (*lead time*) permintaan material (*Material Request* / MR) dari tanggal pengajuan hingga tanggal penyerahan barang.

##  Fitur Dashboard
1. **Filter Kategori Waktu**: Memilah transaksi secara otomatis berdasarkan kategori:
   - **Cepat**: $\le$ 1 hari
   - **Standar**: 2 - 3 hari
   - **Lambat**: $>$ 3 hari
2. **Metrik Utama (KPIs)**: Menampilkan total transaksi, rata-rata rentang hari, dan waktu terlama secara dinamis.
3. **Visualisasi Grafik**: Grafik batang interaktif untuk melihat distribusi jumlah kategori pemenuhan.
4. **Tabel Detail Transaksi**: Menampilkan data lengkap beserta status kategori per baris tanggal.

## Teknologi yang Digunakan
- **Python** (Bahasa Pemrograman)
- **Pandas** (Pengolahan Data)
- **Streamlit** (Framework Dashboard Web)
- **GitHub & Streamlit Cloud** (Deployment)
